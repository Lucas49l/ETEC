pwd : Mostra o diretório em que está

ls : Lista as pastas e arquivos
ls -la : Lista tudo do diretório inclusive arquivos ocultos

mkdir "nome da pasta" : cria uma pasta no diretório. se der espaço pode criar mais de uma pasta
touch "nome do arquivo" : Cria um arquivo no diretório
rm -rf "nome do arquivo/pasta" : Deleta o arquivo ou pasta do diretório

curl "nome do site" : exibe o codigo html no terminal

cd "nome da pasta": entra na pasta que está dentro do diretório atual
cd .. : Volta uma pasta
cd../../.. : Volta 3 pastas
cd : vai pra raiz do sistema


processo  -> desenvolvedor -> homolog -> desenvolvedor
